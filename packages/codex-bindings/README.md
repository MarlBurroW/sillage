# @sillage/codex-bindings

TypeScript bindings for the `codex app-server` protocol, generated by the installed
Codex binary (`pnpm codex:types`). A separate package: `@sillage/protocol` is
CLI-neutral, so a vendor's 500-file dump did not belong there.

Only the server's Codex adapter and protocol drift assertions depend on it.
`pnpm codex:types:check` fails if committed content has drifted from the binary.

Coverage and checks: [Codex integration](../../docs/CODEX.md).
