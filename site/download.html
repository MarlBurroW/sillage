Before the first launch

The apps are not signed yet, and Sillage needs Git. Each system has one or two things to know.

macOS: Git and the first-open permission

Move Sillage from the disk image to Applications. Install Apple’s Command Line Tools if Git is missing. The app is not notarized yet; macOS may require System Settings › Privacy & Security › Open Anyway on first launch.

macOS setup guide
Windows: Git and SmartScreen

Install Git for Windows, then run the Sillage installer. Installation is per user. The app is not signed yet, so SmartScreen may show a first-run warning; the guide explains the More info › Run anyway step.

Windows setup guide
Linux: choosing the package

On Debian or Ubuntu, use the .deb package: it installs Git and the AppArmor profile Chromium’s sandbox needs on recent Ubuntu versions. AppImage is there for other distributions. Choose x64 or arm64 to match your processor.

Linux setup guide
Reaching Desktop from your phone

Enable private Tailscale access in Desktop’s Remote access settings. The app must remain open and the computer awake.

Sillage Server

Install Sillage on a host you control. The background service keeps agents working when you close the browser, as long as the host stays awake.

For Linux with systemd, or macOS on Apple Silicon. Run it in the host’s terminal.

curl -fsSL https://raw.githubusercontent.com/MarlBurroW/sillage/main/install.sh | bash

Read the installer before running it

  1. Install on your host

    The installer prepares the runtime and the background service.

  2. Open your workspace

    The first-run tour creates your account and connects your agents.

  3. Connect your devices

    Use Tailscale or a protected HTTPS address, following the remote access guide.
