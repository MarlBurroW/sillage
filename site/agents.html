Get Sillage

Five coding agents, each driven through its own CLI.

Sillage installs and runs the vendors’ tools on your machine. Their models, tools and account rules stay theirs; the projects, context and interface around them are shared.

Anthropic

Claude Code, with its plans, subagents and permissions.

Work through a plan, follow tool calls and subagents, and review the files Claude changes. You keep the native agent, with your projects and conversations gathered around it.

Claude Code integration guide

Accounts

Use the CLI’s sign-in, connect another Claude subscription or add an Anthropic API key.

Controls

Choose among the available models, effort levels and permission modes. Answer Claude’s questions and permission requests in the conversation.

Shared context

Sillage supplies shared instructions, project memory, skills and MCP tools alongside Claude’s native capabilities.

Model availability and subscription limits come from your Claude account.

OpenAI

Codex threads you can resume.

Keep the coding conversation, its tools and the branch it changes in the same view. Resume a thread, choose its model and effort, and inspect the result as you go.

Codex integration guide

Accounts

Connect a ChatGPT subscription through device-code sign-in or configure an API key. Pick the account for each conversation.

Controls

Model catalogs follow the selected account. Effort levels and permission controls stay in the composer.

Shared context

Use your Sillage project instructions, memory, skills and MCP servers. Continue a conversation with another agent when the next step calls for it.

Model access and supported controls depend on the installed CLI and the selected account.

Open source

OpenCode, with the model providers you configured.

Bring OpenCode’s provider choices into the same workspace as your other agents. The conversation, files and tasks stay together whichever model answers.

How OpenCode receives shared context

Providers

Use the providers configured in OpenCode, including local models when the provider supports them.

Controls

Read streamed responses and tool activity, manage permissions and keep project files beside the thread.

Shared context

Instructions and the memory index accompany each message. Skills, MCP tools and conversation handoffs connect the rest of your workflow.

Available models and media support are determined by your OpenCode provider configuration.

xAI

Grok Build, xAI’s coding agent.

Use xAI’s native coding agent from the same workspace. Follow its changes, respond to its questions and keep the conversation with the work it belongs to.

Accounts guide

Accounts

Use a Grok subscription or an xAI API key and choose the account for the conversation.

Controls

Follow tools and responses in the same conversation view, with the options the native agent exposes.

Shared context

Project instructions and memory enter the session when it is created. The same board, worktrees, skills and MCP tools remain close by.

Grok receives shared instructions at session creation; an existing session keeps the context it started with.

Google

Antigravity, Google’s own agent for Gemini.

Run Google’s official Antigravity agent with its native tools and permissions. Choose among its models and thinking levels while keeping the same Sillage project workflow.

Antigravity integration guide

Accounts and models

Use the account choices, commands, history import and model-specific thinking levels Antigravity exposes.

Shared context

Share project instructions, memory, skills and MCP tools. Transfer conversations in both directions with the other agents.

Limits

Forks create a new session with portable context. Manual compaction and live steering are unavailable; messages can wait in the queue.

The protocol does not expose native forks, manual compaction or live steering, and Sillage shows that rather than hiding it.

What stays the same when you change agent

Sillage runs the native agents on your machine. The parts around them don’t move.

The conversation view

Messages, tool activity, questions and files are laid out the same way for every agent.

The project context

Shared instructions, memory and skills carry your working conventions.

The workspace

The board, Git worktrees, file explorer and code review stay next to the task.

Hand a conversation to another agent

Choose another agent and a context budget. A new conversation opens with the selected history, in the same worktree and on the same task card. The original stays available, with a link back from the new one.

Handoff guide

The original request

Your first message gives the next agent the starting point for the work.

The latest exchanges

Recent messages keep their text, order and roles, up to the selected budget.

Relevant tool activity

Recent tool inputs and outputs accompany those exchanges, with length limits.

References to earlier history

The next agent can read omitted exchanges from the original conversation when it needs them.

Reasoning, attachments and native tool state are not transferred. You write the next request in the new conversation.
