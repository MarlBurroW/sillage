Premiers pas

De zéro à une première conversation. Desktop se passe de compte ; sur Server, la visite guidée du premier lancement crée le tien.

  1. Installe Sillage

    Desktop est une application pour ton ordinateur. Server est un service sur un hôte que tu contrôles, joignable depuis tes autres appareils. Choisir et télécharger

  2. Ouvre-le

    Desktop s’ouvre dans sa propre fenêtre. Server répond à l’adresse http://127.0.0.1:7317 sur l’hôte, et sa visite guidée du premier lancement crée le premier compte, celui de l’administrateur.

  3. Connecte tes agents

    Installe les CLI que tu veux depuis la visite guidée ou depuis Réglages, puis connecte-toi avec tes propres abonnements ou clés API. Les connexions déjà présentes sur la machine sont réutilisées. Comptes des agents

  4. Ouvre un projet

    Un projet est un dossier sur cette machine. Ouvre un dépôt existant, ou crée un projet dans le dossier que tu veux utiliser.

  5. Lance une conversation

    Choisis un agent et l’endroit où il travaille : la racine du projet, un worktree existant, ou une nouvelle branche que Sillage crée pour la tâche. Essaie « Explique comment ce projet est organisé. » Ce qu’offre une conversation

  6. Reprends ailleurs

    Server garde les sessions actives une fois le navigateur fermé. Ouvre-le depuis ton téléphone par Tailscale ou une adresse HTTPS. Accès distant
