Vibe-code from anywhere.

A web UI for the native Claude Code and Codex CLIs. They keep running on your own machine, under your account, with your subscriptions. You stop needing a terminal to reach them.

Install Source on GitHub

Keep the harness. Drop the terminal.

Coding agents work best inside the harness their vendor ships: its prompts, its tools, its permission flow. Reimplementing that is how you end up with a worse agent. So Sillage does not reimplement it. It supervises the real CLI processes and streams what they emit.

What it does replace is the terminal, which is a miserable place to be on a phone, and a poor fit for the half of your ideas that show up away from a keyboard. Open the tab on any device, answer the permission prompt, read the diff, keep going.

Around the conversation

Chat is the middle of it. The repository, the history and the work in flight stay one panel away.

What you get

  • Native CLIs

    Claude Code and Codex run unmodified, with the subscriptions and credentials already on your machine.

  • Real conversations

    Streaming replies, tool calls, reasoning, attachments and interactive permission prompts. Resume a session later, from another device.

  • Workspace panel

    File explorer, editor, diffs, commit history and terminals, next to the conversation that touched them.

  • Projects and worktrees

    Point it at your repositories. Isolate an experiment in a git worktree without losing the main branch.

  • Mobile-first PWA

    Installable, one-handed, with a push notification when a turn finishes so you can put the phone down.

  • Built-in updates

    The UI shows the installed version, what changed since, and updates the installation for you.

Install

Docker, or a systemd user service on Linux. Both bind to localhost by default.

# docker-compose.yml
services:
  sillage:
    image: ghcr.io/marlburrow/sillage:latest
    ports: ["127.0.0.1:7317:7317"]
    volumes:
      - sillage-data:/home/node/.local/share/sillage
      - ~/.claude:/home/node/.claude
      - ~/.codex:/home/node/.codex
      - ~/projects:/home/node/workspace
volumes:
  sillage-data:

The image ships with both CLIs preinstalled. Mount your credential directories and your projects, then create the first account:

docker compose exec -it sillage node /app/server/cli/user-create.js
curl -fsSL https://raw.githubusercontent.com/MarlBurroW/sillage/main/install.sh | bash

Linux x64 or arm64, systemd, Node 22+, with claude and codex already authenticated on the host. It installs under ~/.local/share/sillage, sets up a user service and creates the first account. Later updates happen from the UI.

A word on security

Sillage is built for a trusted circle, not for the open Internet. Agents run under your system account with your credentials, every account on the instance shares them, and terminal mode is a full shell. The server listens on localhost and does not terminate TLS: reach it through a VPN, a tailnet or a reverse proxy you control.
