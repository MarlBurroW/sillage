Sillage

Vibe-code from anywhere.

A self-hosted, mobile-first web UI that drives the native Claude Code and Codex CLIs on your own machine. The official agent harnesses, without the terminal.

Install GitHub

Why it exists

Coding agents work best inside their official harness: the prompts, tools and permission flows their vendors ship with the CLI. But a terminal is a poor fit for a phone, and half the ideas worth trying show up away from a keyboard. Sillage keeps the CLIs and replaces the terminal with a web UI you can open from anywhere. Built for personal use first, shared because it holds up.

What you get

  • Native CLIs

    Claude Code and Codex run unmodified, with your existing subscriptions and credentials.

  • Mobile-first PWA

    Installable, push notifications when a turn finishes, designed for one-hand use.

  • Real conversations

    Streaming chat, tool calls, interactive permission prompts, full-text search across history.

  • IDE panel

    File explorer, editor, diffs and terminals, next to the conversation that produced them.

  • Projects and worktrees

    Point it at your repositories; isolate experiments in git worktrees.

  • Built-in updates

    The UI shows the installed version, what changed since, and updates itself in one click.

Install

# docker-compose.yml
services:
  sillage:
    image: ghcr.io/marlburrow/sillage:latest
    ports: ["127.0.0.1:7317:7317"]
    volumes:
      - sillage-data:/home/node/.local/share/sillage
      - ~/.claude:/home/node/.claude
      - ~/.codex:/home/node/.codex
      - ~/projects:/home/node/workspace
volumes:
  sillage-data:

The image ships with the claude and codex CLIs preinstalled; mount your credential directories and your projects. Then create the first account: 

docker compose exec -it sillage node /app/server/cli/user-create.js
curl -fsSL https://raw.githubusercontent.com/MarlBurroW/sillage/main/install.sh | bash

Linux x64/arm64 with systemd and Node 22+. Installs under ~/.local/share/sillage, runs as a systemd user service, and updates from the web UI afterwards. No Docker required.

A word on security

Sillage is built for a trusted circle, not for the open Internet. Agents run under your system account with your credentials, and every account on the instance shares them. It listens on localhost and does not terminate TLS: reach it through a VPN, a tailnet or a reverse proxy you control.
