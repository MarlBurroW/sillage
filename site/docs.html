Getting started

From nothing to a first conversation. Desktop needs no account; on Server, the first-run tour creates yours.

  1. Install Sillage

    Desktop is an app for your computer. Server is a service on a host you control, reachable from your other devices. Choose and download

  2. Open it

    Desktop opens in its own window. Server answers at http://127.0.0.1:7317 on the host, and its first-run tour creates the first account, which is the administrator.

  3. Connect your agents

    Install the CLIs you want from the tour or from Settings, then sign in with your own subscriptions or API keys. Sign-ins already on the machine are reused. Agent accounts

  4. Open a project

    A project is a folder on that machine. Open an existing repository, or create a project in the folder you want to use.

  5. Start a conversation

    Pick an agent and where it works: the project root, an existing worktree, or a new branch Sillage creates for the task. Try “Explain how this project is organized.” What a conversation offers

  6. Pick it up elsewhere

    Server keeps sessions running with the browser closed. Open it from your phone through Tailscale or an HTTPS address. Remote access
