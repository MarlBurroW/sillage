## Conversations

- Réparer les images Markdown en ligne enregistrées dans un worktree relié après le début de la conversation. Les images s’affichent dans le fil et s’ouvrent dans le visualisateur d’images.
- Ajouter le mode concentration : masquer la navigation alentour et les contrôles secondaires en préservant les brouillons et la position de lecture.
- Présenter les actions de la conversation en icônes avec des infobulles rapides, et dans une rangée d’actions séparée au téléphone.
- Choisir l’effort de raisonnement avec un curseur qui glisse en continu et se cale au relâchement, au clavier comme au toucher.
- Afficher les messages envoyés immédiatement, avant que le CLI ait fini de démarrer.
- Réparer les liens de fichiers Windows dans les conversations, y compris vers des fichiers audio.

## Réglages et intégrations

- Organiser les réglages en groupes de navigation fixes et simplifier le pied de la barre latérale.
- Montrer descriptions et liens en parcourant les skills avant de les ajouter.
- Appliquer les serveurs MCP activés en cours de session, et ajouter une aide à la configuration des jetons Bearer.
- Refuser les CLI désactivés dans la configuration du serveur.

Ces améliorations sont communes à Sillage Server et Sillage Desktop. Aucune nouvelle migration de base de données depuis v0.28.0. Après la mise à jour de Server, recharge une conversation déjà ouverte pour retenter les images qui manquaient jusque-là.

## Téléchargements

- **Windows** : `Sillage-win-x64.exe`
- **macOS Apple Silicon** : `Sillage-mac-arm64.dmg`
- **Linux** : paquets `.deb` et AppImage pour x64 et arm64
- **Server** : archives Linux x64/arm64 et macOS arm64 ; image Docker `ghcr.io/marlburrow/sillage:0.29.0`
