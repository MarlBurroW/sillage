Les mentions `@` proposent désormais les dossiers et fonctionnent dans tous les projets, le composer nomme ses raccourcis de saisie, et une radio joue depuis le rail.

**Mentions**
- Taper `@` propose désormais les dossiers en plus des fichiers. Un dossier se mentionne sous la forme `@path/` : Entrée ou un clic le mentionne, Tab ou le chevron de la ligne l’ouvre pour choisir quelque chose à l’intérieur (le chevron fonctionne sur les écrans tactiles). Claude Code reçoit la liste du contenu du dossier ; Codex et les autres CLI reçoivent le chemin et le lisent avec leurs outils.
- Corrigé : dans un dossier de projet ignoré par un dépôt Git englobant (par exemple un dépôt de dotfiles dans ton dossier personnel), `@` répondait « Aucun fichier ne correspond » pour tout. Sillage parcourt maintenant le dossier quand Git ne liste rien, ce qui corrige aussi la recherche de l’explorateur et la palette dans ce cas. Un listage en échec le dit désormais, au lieu de ressembler à un résultat vide.

**Composer**
- Le composer vide liste les préfixes qu’il comprend (`@` fichiers et dossiers, `@@` sessions, `#` tickets…), et le menu Insérer devient « Raccourcis » : citer une session ou un ticket ne demande plus de recherche.

**Radio**
- Un interrupteur marche/arrêt dans le rail lance Claude FM en arrière-plan ; la lecture continue pendant que tu navigues. Réglages › Personnel › Radio permet à chaque compte de choisir une autre vidéo ou un autre live YouTube.

Éditions Server et Desktop. Aucune migration de base de données.
