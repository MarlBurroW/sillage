Les projets peuvent désormais relier des dossiers supplémentaires dans Fichiers : les expériences et les travaux connexes hors du dépôt principal restent à portée de main.

- Rattacher des dossiers existants à un projet et les retrouver dans toutes ses sessions et sur tous les appareils. Les propriétaires du projet gèrent ces liens ; les membres peuvent parcourir et modifier les fichiers partagés.
- Changer de dossier dans le panneau Fichiers, et revenir à tes dossiers récents personnels sans changer le dossier de travail de l’agent.
- Inclure des dossiers supplémentaires à la création d’un projet. Les agents peuvent lister et rattacher des dossiers de projet avec les outils de Sillage.
- Disponible dans les éditions Server et Desktop.

Base de données : deux migrations additives pour les dossiers personnels de l’explorateur et les dossiers partagés des projets (0074–0075), appliquées automatiquement au premier démarrage.
