Des retours d’utilisateurs d’OpenCode : un sélecteur de modèle où l’on se repère, et un composer qui montre ce qui part avec ton message.

**Modèles OpenCode**
- Le sélecteur de modèle range les modèles d’OpenCode par fournisseur (GitHub Copilot, Anthropic, OpenCode Go…) sous des titres de section, au lieu d’une seule liste triée par nom où le même modèle apparaissait une fois par fournisseur.
- Le modèle **Auto** de GitHub Copilot, qui laisse le routeur de Copilot choisir le modèle de chaque session, ouvre la section Copilot quand ton compte dispose d’un pool Auto.
- Une section Récents, en haut, liste les derniers modèles que tu as utilisés avec OpenCode. La recherche la laisse de côté, pour que chaque modèle n’apparaisse qu’une fois dans les résultats.
- Réglages › Défauts des CLI utilise le même panneau avec recherche dès qu’un CLI liste plus de huit modèles : un modèle OpenCode par défaut peut donc s’y choisir aussi.

**Composer**
- Les fichiers choisis dans les suggestions `@`, les skills choisis avec `$` et une `/command` en tête que le CLI connaît sont teintés dans la zone de saisie : teinté veut dire joint. Un chemin tapé à la main reste sans teinte, car il n’est pas envoyé comme fichier.

Disponible dans les éditions Server et Desktop. Aucune migration de base de données.
