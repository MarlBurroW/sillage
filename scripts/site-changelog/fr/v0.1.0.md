Première version publique de Sillage : une interface web auto-hébergée, pensée d’abord pour le mobile, qui pilote les CLI Claude Code et Codex sur ta propre machine.

- Des conversations avec Claude Code et Codex dans une application web installable, pilotées par un serveur qui supervise les CLI.
- Les sessions Claude Code lancées dans un terminal s’importent depuis l’écran de nouvelle conversation, et les tours joués dans le terminal sont rattrapés à l’ouverture de la conversation.
- Un panneau latéral avec un explorateur de fichiers (menu contextuel, recherche de fichiers), un éditeur, des diffs et des terminaux.
- Des réglages par catégorie, dont des réglages de lecture pour le texte des messages : taille, interligne et douceur de l’encre.
- Installation par une image Docker ou par un script en une ligne pour Linux x64/arm64 avec systemd. Réglages › À propos affiche la version installée, et un administrateur peut mettre à jour en un clic une installation faite avec l’installateur.
