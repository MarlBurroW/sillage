Sillage lance désormais les CLI d’agents installés sur la machine et sait les installer lui-même, donne aux sous-agents leur propre vue, et ajoute la gestion des serveurs MCP et une API de tâches.

- Sillage lance Claude Code et Codex tels qu’installés sur la machine, au lieu d’une copie livrée avec la release, montre quels CLI sont installés et dans quelle version, et peut installer ceux qui manquent depuis l’interface. L’image Docker n’inclut plus les CLI.
- Les sous-agents quittent le fil principal : leurs fils complets s’ouvrent dans un onglet du panneau latéral, et un bandeau au-dessus du composer montre ceux qui tournent encore.
- Les serveurs MCP se déclarent une seule fois pour tous les CLI, depuis un écran de réglages, et s’activent par conversation. Leurs en-têtes et variables d’environnement peuvent faire référence à des secrets d’un nouveau dépôt de secrets chiffré.
- Une API de tâches sous `/api/v1` pour les clients machine, avec jetons d’API, webhooks signés et conversations marquées comme pilotées par l’API.
- L’interface est disponible en anglais et en français, avec un sélecteur de langue dans Apparence.
