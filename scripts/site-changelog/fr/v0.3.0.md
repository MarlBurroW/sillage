Les agents reçoivent un serveur MCP Sillage intégré pour chercher dans les conversations passées du projet et voir ce que font les autres sessions, et la barre latérale signale les conversations non lues.

- Le serveur MCP intégré propose `search_history` et `read_conversation` pour l’historique du projet, `list_sessions` et `count_active_sessions` pour les sessions au travail, et `find_file_edits` pour savoir quelle session a modifié un fichier. Il est activé par défaut et se désactive par conversation, par préréglage de projet ou pour toute l’instance.
- Les sessions Claude Code démarrent avec un court aperçu de ce qui se passe déjà dans le projet.
- Les conversations non lues sont signalées dans la barre latérale, pour chaque compte.
- Sillage vise Codex 0.146, la version qui liste ses modèles GPT-5.6.
- Le sélecteur du dossier racine peut créer un dossier, et les images lues par un outil Read s’affichent dans l’appel d’outil.
