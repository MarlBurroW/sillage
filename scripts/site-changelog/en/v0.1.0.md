First public release of Sillage: a self-hosted, mobile-first web interface that drives the Claude Code and Codex CLIs on your own machine.

- Conversations with Claude Code and Codex in an installable web app, driven by a server that supervises the CLIs.
- Claude Code sessions started in a terminal can be imported from the new conversation screen, and turns made in the terminal are caught up when the conversation opens.
- A side panel with a file explorer (context menu, file search), an editor, diffs and terminals.
- Settings by category, with reading settings for message text: size, line height and ink softness.
- Install with a Docker image or a one-line script for Linux x64/arm64 with systemd. Settings › About shows the installed version, and an admin can update an installer-based setup in one click.
