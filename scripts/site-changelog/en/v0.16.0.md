Sillage 0.16.0 reworks how skills are browsed and installed from the composer, makes activity easier to read, and adds tooltips to the interface's controls.

## Skills

- Browse the composer's skills in a wider window, with two separate views for the Sillage library and the session's inventory. Long descriptions unfold on demand, and access to library management stays visible.
- Install several skills from a Git catalog in one operation: checkboxes, selection of all filtered results and a shared destination. The catalog stays open on the same source after the installation.
- Keep the successful installations when one skill fails, and fix name conflicts from the preview without starting the whole flow over.
- On a phone, go from the list to the preview without losing the selection.
- Clarify the existing update flow: refresh the source, review the differences, then apply the changes.

## Interface

- Give global and project activity a clearer hierarchy, with more readable states and visual cues.
- Show tooltips on the interface's controls, to make them easier to identify with the mouse and the keyboard.

## Validation

Type checking, lint, 142 server tests, a full build and Playwright runs of the skills and the composer on desktop and phone passed. No new database migration since v0.15.0.
