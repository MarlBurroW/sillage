Sillage v0.25.0 makes conversations easier to read and sessions easier to move between, on Server as on Desktop.

## What's new

- **References between conversations**: type `@@` to find and cite a session. References in messages and in agents' replies open a preview and the original thread. An Insert menu presents the shortcuts for files, sessions, tickets, commands and skills.
- **Six tool displays**: discreet lines, timeline, grouping by purpose, previews, compact console or classic display. Details show inputs, outputs and file changes; failures remain easy to spot in collapsed groups.
- **Reworked navigation**: a simpler session list, titles given by agents, and settings organized to cut down on long scrolling.
- **Automatic Desktop updates**: download in the background, installation from About or on quit. Debian packages ask for administrator authorization; on macOS, the app must be in Applications.

## Responsiveness and fixes

- Long conversations load progressively, and full tool outputs are fetched on demand.
- Less memory used by histories, images and Claude transcripts; loads that are no longer needed are cancelled.
- The side panel no longer reopens when you switch conversations through its worktree label.
- Applying Desktop updates is more reliable, notably on Windows and with Linux AppImages.

The README, the features guide and the website present the new uses. References, tool displays and navigation improvements apply to both editions; automatic updates apply to Desktop.
