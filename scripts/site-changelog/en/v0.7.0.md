Sillage 0.7.0 strengthens support for Codex and its Astra models: structured questions become interactive forms, and the CLI's activity stays visible while it works.

- Blocking and asynchronous questions, free-form answers, simultaneous requests and targeted cancellations, sub-agents included.
- Plans, diffs, live tool output, searches, images, hooks, warnings and unknown events can be viewed.
- App Server connection updated for Codex 0.153.2, and token usage fixed.
- Personal favorites, file and folder uploads with progress, per-project Claude/Codex settings and a configurable session limit.
- Explicit turn errors; file links in the thread and the Helm chart, both added since the previous release. Chart 0.2.0 uses the 0.7.0 image by default.

Older logs and presets remain readable. The favorites migration applies automatically at startup.

Validated by 18 tests, desktop and mobile browser checks and real probes against Astra, along with type checking, lint, build and the protocol check.
