## Personal discussions and assistant

Each account now has conversations outside any project, with a lasting workspace and a personal memory shared across CLIs. An idea born in a discussion carries on in a project with an explicit brief and the chosen files; personal assistants drive the project sessions they start, and discover models without borrowing another project.

## Accounts and models

- Adding a Claude subscription now takes a single code: the usage gauge is read from the same token, without a second sign-in. On Desktop, the CLI no longer opens a tab of its own.
- The model list follows the chosen account for Codex, Claude and Grok Build: each account is probed with its own credentials, and Codex no longer shares its model cache between accounts.
- The model panel has a button to reload the list from the CLI without waiting for the cache to expire.

## API and MCP permissions

Each key independently allows its own CLIs, models and efforts, with the same policy enforced by the REST API and by the MCP server. Permissions change without regenerating the secret, and the "API & MCP" settings are reorganized around keys and connection guides.

## Skills

Installed skills, discovery, sources and updates are split into tabs. Creating a source opens in its own window, the search scope is explicit, and installation stays focused on the chosen skill.

## Claude Code 2.1.312

Sillage targets Claude Code 2.1.312 and Agent SDK 0.3.312. Permissions, questions, plan reviews and elicitations expire when the CLI abandons the request, instead of staying open with nobody listening. "Don't answer" marks the question as skipped in the tool result.

## Fixes

- Reordering sessions in the sidebar works again after the first drop.
- Migrations preserve references inherited from older versions instead of rejecting an otherwise valid database.

## Installation and upgrade

Desktop packages are available for Windows x64, macOS Apple Silicon and Linux x64/arm64. Server archives and the multi-architecture Docker image are published as well. Desktop downloads the update automatically; it installs from **Settings › About** or when the app closes, except for the `.deb` package.
