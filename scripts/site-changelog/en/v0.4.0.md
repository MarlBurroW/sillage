Each project gets a board that agents can read and write, idle conversations are archived automatically, and prompts can be dictated.

- A board per project, with drag and drop and a session started from a card. Agents read it with `list_cards` and `read_card`, and add notes to their card with `add_card_note`.
- Conversations can be archived, and read conversations left idle are archived automatically. The delay and the time of the pass are set in the settings, and a pass can be run by hand.
- Dictate a prompt through an AI transcription provider (an OpenAI-compatible API such as Mistral, Groq, OpenAI or a self-hosted Whisper), with a microphone level meter.
- The composer suggests the CLI's commands after `/` (Claude Code) and its skills after `$` (Codex).
- Creating a project can clone a repository.
