Fixes to the installer and the built-in update, and faster opening of long conversations.

- The installer checks the native database module before starting the service and rebuilds it if needed, enables lingering, reports a failed first-account creation, and says it is done only once the server answers. The built-in update runs the same check before switching versions.
- The service logs to the system journal, and a start limit stops a crash loop at the fifth failure.
- The Claude model list and usage gauge use the installed CLI, so Claude no longer looks missing when its CLI is installed.
- `better-sqlite3` moves to 13.x, so release archives run under Node 22 and Node 24 without recompiling.
- Long conversations open faster: replay merges streamed text fragments, and tool outputs over 8 KB are sent as a preview and load in full when their card opens.
