Sillage also installs as a desktop app, on macOS and Linux: no server to set up, no account to create.

## Desktop app (macOS, Linux)

- Download Sillage as an app, starting with this release: `.dmg` (and `.zip`) for Apple Silicon Macs, `.deb` and AppImage for Linux x64 and arm64. The app bundles the release's server and its own Node, and opens Sillage in its window.
- The agents are the user's own CLIs, with the user's sign-ins. The app reads the environment of the login shell: CLIs installed with Homebrew, npm or nvm are found as they are in the terminal. It can also install missing CLIs with its bundled npm.
- No sign-in: the app signs in its single user by itself. Its server listens on `127.0.0.1` and serves only the app's window (`Host` and `Origin` checks).
- The interface adapts to the instance profile, reported by `GET /api/system/instance`. On desktop, it hides the password, sign-out, push notifications, user accounts and the service worker, and "About" points to the new version to download. Hosted instances do not change.
- The app is not notarized by Apple yet: on first launch, allow it in System Settings › Privacy & Security ("Open Anyway"). On Ubuntu 24.04 and later, prefer the `.deb`, which installs the AppArmor profile Chromium needs.
- Agents work while the app runs, on this computer only: no access from a phone, no push notifications, no webhooks from the Internet. For those, a server remains the right way. The [`docs/desktop.md`](https://github.com/MarlBurroW/sillage/blob/main/docs/desktop.md) guide details what changes, where the data lives and how to uninstall.
- Each release builds the app on each platform's native runners and actually launches it before publishing. CI does the same for Linux on every PR.

## Interface

- Show the branch and the worktree in a conversation's header, with a dot when the tree has uncommitted changes; a click opens the Git tab.
- Center the empty states of every side panel tab.
- Align the PWA icons and the share image with the app's indigo accent.
