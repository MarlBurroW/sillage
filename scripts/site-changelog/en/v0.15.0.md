Sillage 0.15.0 adds scheduled tasks, moves project creation and project settings next to the project switcher, and lets you browse skills from the composer.

## What's new

- Schedule one-off or recurring tasks: each run opens a new conversation, with the next runs and the history reachable from the sidebar. Agents can also schedule tasks through the Sillage MCP server.
- Create a project straight from the project switcher, and open the active project's settings next to its name. Projects leave the general settings.
- Browse skills from the composer: search, descriptions, global or project scope, the configured library and the inventory reported by the CLI. Claude exposes its skills and commands in a single list, which is labeled as such.

## Interface

- Show "Settings" in place of the user name, and keep it selected on every settings sub-page.
- Keep the selection highlight uniform in the project switcher, including on hover and next to the pin button.
- Keep Ultracode in the composer's detailed settings, with a team icon and no extra shortcut.
- Present scheduled tasks and the demo video on the website.

## Validation and upgrade

Type checking, 142 server tests, lint and Playwright runs on desktop and phone passed. This release adds the additive scheduled tasks migration for installations coming from v0.14.0.
