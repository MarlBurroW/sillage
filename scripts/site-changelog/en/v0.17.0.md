Sillage 0.17.0 brings the everyday git workflow into the Git tab, a command palette that searches projects, conversations, files and more from a single input, multiple selection in the file explorer, and a Services page that shows what agents start.

## Git

- Run the everyday git workflow from the Git tab, without a terminal: stage and unstage files, commit or amend (Ctrl/⌘+Enter), fetch, pull with merge or rebase, push or publish the branch, force push with lease.
- Manage local and remote branches (create, switch, merge, delete) and stashes (create, apply, pop, drop).
- Act on a commit: new branch here, revert, soft, mixed or hard reset, each explained and confirmed.
- Drive an operation in progress (a merge, rebase or revert stopped on conflicts): mark files as resolved, continue or abort.
- Turn git's refusals into suggested remedies: force with lease, stash then switch, delete anyway.
- Everything goes through the git binary in the repository: hooks, configuration, signing and the credential helper apply as they do from the shell.

## Command palette

- A single input, no filters: projects, conversations, message text, files from every repository (VS Code-style fuzzy matching), tickets, scheduled tasks, skills, MCP servers, settings sections and a few commands.
- Results are grouped by project, with the current project first at equal relevance; Tab moves to the next group.
- Naming a project narrows the search to it ("nimbus cache"), and naming a result type lists that type ("skill", "mcp", "ticket").
- Opening a file shows it in the panel, worktrees included, with the cursor in the editor.

## File explorer

- Multiple selection with Ctrl-click, Shift-click and Ctrl+A; full keyboard support (arrows, Enter, Space, F2, Delete, type-ahead); shortcuts shown in the menus.
- Cut, copy, paste, duplicate, copy the absolute or relative path, drag several entries, download a folder or a selection as a streamed zip.
- Expanded folders survive a search or closing the column, and a tab follows its file when it is renamed or moved, unsaved draft included.
- On a phone, "Select" in a row's menu switches to selection mode.

## Services

- The page now lists permanent apps (`sillage-app-*`) with their state, ports and origin, and can stop, restart or remove them.
- Commands started by agents and terminals fold into one line per process tree, with subprocesses, ports and total memory; the shell wrapping Claude Code puts around a command is removed to show the command the agent asked for, and values that look like secrets are masked.
- Processes detached from the daemon form a third list.

## Settings and navigation

- MCP, Secrets, Git access, API tokens and Accounts pages: the list comes first, and the creation form opens on demand; a switch enables an MCP server, the app's own confirmation dialog guards account deletion, and token scopes are explained.
- Pinned projects are saved on the server, per account, and follow the user from one device to another; existing local pins are carried over once.
- The empty states of the Sub-agents and MCP panels are centered.

## Validation

Type checking, lint, 180 server tests, a full build and Playwright runs of the palette, the Git tab, the explorer and Services on desktop and phone passed. One additive migration since v0.16.0: `0032_project_pins` (table `project_pins`).
