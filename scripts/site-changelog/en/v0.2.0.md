Sillage now runs the agent CLIs installed on the machine and can install them itself, gives sub-agents their own view, and adds MCP server management and a task API.

- Sillage launches the Claude Code and Codex installed on the machine instead of a copy shipped with the release, shows which CLIs are installed and in which version, and can install missing ones from the interface. The Docker image no longer includes the CLIs.
- Sub-agents leave the main thread: their full threads open in a side panel tab, and a banner above the composer shows those still running.
- MCP servers are declared once for every CLI from a settings screen and enabled per conversation. Their headers and environment variables can reference secrets from a new encrypted secret store.
- A task API under `/api/v1` for machine clients, with API tokens, signed webhooks, and conversations marked as driven by the API.
- The interface is available in English and French, with a language selector in Appearance.
