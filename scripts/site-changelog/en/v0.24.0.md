## News during turns

Sillage can show articles while the agent works: one headline at a time, renewed every 12 seconds, with its source, its date and a link to the article. The rotation pauses on hover or keyboard focus; buttons also let you pause the rotation, skip to the next headline or hide the news for the turn.

In **Settings › News**, turn the feature on and put together your own selection of RSS or Atom feeds. Hugging Face, Google DeepMind and OpenAI are offered to start with. You can test a source before adding it, disable or remove it, and find recent articles again after the turn ends.

News is **off by default**. It works without calling an AI model, with an hourly fetch and a cache local to the instance. Each Server account keeps its own preferences; on Desktop, they belong to the local account. Downloads are capped and internal network addresses are refused.

## More comfortable conversations

- **Customizable activity indicator** in Appearance: Sillage, Wave, Orbit, Ink, Constellation or Breath, with a preview before choosing.
- **Adjustable content width**, from 768 to 1,600 pixels, in Appearance.
- **Image preview before sending**: click an attachment in the draft to open it in the viewer.
- **Activity grouped by project** in a single list, with cues to tell session states apart.

## Windows fix

Existing worktrees are no longer wrongly reported as missing when Git and Windows use different path separators. Reading paths that contain accented characters is fixed as well.

## Installation and upgrade

**Sillage Server** archives are available for Linux x64/arm64 and macOS Apple Silicon. **Sillage Desktop** is available for Windows x64, macOS Apple Silicon and Linux x64/arm64.

This release adds the SQLite migration `0049_natural_tenebrous`, applied automatically at startup to create the feed cache. Existing preferences are kept.

Validation: type checking, lint, 351 server tests, a production build and Playwright runs on desktop and phone. The Server and Desktop profiles were also checked on the assembled package.
