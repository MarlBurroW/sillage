Agents get a built-in Sillage MCP server to search the project's past conversations and see what other sessions are doing, and the sidebar marks unread conversations.

- The built-in MCP server offers `search_history` and `read_conversation` for the project's history, `list_sessions` and `count_active_sessions` for the sessions at work, and `find_file_edits` to tell which session changed a file. It is on by default and can be turned off per conversation, per project preset or for the whole instance.
- Claude Code sessions start with a short overview of what is already happening in the project.
- Unread conversations are marked in the sidebar, per account.
- Sillage targets Codex 0.146, the version that lists its GPT-5.6 models.
- The root folder picker can create a folder, and images read by a Read tool show in the tool call.
