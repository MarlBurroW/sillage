Sillage now drives Grok Build, follows each worktree until it is cleaned up, shows what each turn changed in the repository, and lets a conversation continue in another CLI.

## A fourth CLI: Grok Build

- Drive Grok Build (xAI) over the Agent Client Protocol, alongside Claude Code, Codex and OpenCode: same instructions, same memory, same board, same coordination tools. Install it from the settings; the adapter is documented in `docs/GROK.md`.

## Worktrees, graph and checkpoints

- Follow worktree progress: the project page compares every tree git knows about, including those created from the shell, with the default branch (uncommitted, to merge, merged, folder missing), and shows the sessions working in it. The sidebar shows each conversation's branch and state.
- Clean up a worktree in one gesture, after a summary of what would be lost; offer the cleanup in **To decide** when a tree is merged and clean.
- Give agents `create_worktree` and `list_worktrees`, so that Sillage sees the trees they create.
- Show the Git history as a graph of branches and merges, for the current branch or all of them, with a per-commit diff inspector; the side panel becomes a vertical rail of icons.
- Snapshot the repository before and after each turn (the project's "Turn checkpoints" option): each turn lists the files it changed, opens them as diffs and can be undone, with an optional fork of the conversation from that point.
- Continue a conversation in another CLI: the new agent receives a budgeted selection of the thread, as complete messages, with references it can read through Sillage's MCP server.

## Interface

- Combine model and effort into one chip under the composer, and arrange the pinnable settings on two levels that can be sorted; on a phone, the chip alone.
- Open conversation images (attachments, screenshots read by agents, MCP outputs) in a viewer: zoom, pan, rotate, copy as PNG, download.
- Group skill updates: sources fetched at once, applied together, with a readable diff.
- Show the API and the MCP server as two separate entry points in the settings, with a generic guide to connecting an MCP client; let an external MCP client read, wait on, follow up on and interrupt existing sessions.

## Versions and upgrade

Targeted CLI versions: **Claude Code 2.1.301** (SDK 0.3.301), **Codex 0.163.0**, **OpenCode 1.19.3**, **Grok Build 1.0.62**.

This release applies three migrations since v0.18.0 (`0042` to `0044`) for handoffs between CLIs, checkpoints and worktree tracking. The first start backfills the paths of existing conversations (a few seconds on a large database). The migrations apply at startup; keep a backup of your data before updating.

The website and README are updated, with new screenshots (Git graph, worktrees, panel rail, composer).
