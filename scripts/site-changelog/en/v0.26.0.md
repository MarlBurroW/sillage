The Sillage Desktop window bar now follows the Sillage theme, and Sillage supports Google Gemini through the official Antigravity ACP distribution.

## An integrated Desktop window

The window bar now follows the Sillage theme. It replaces the native title bar and menu, stacked one above the other, with a compact header that can be dragged with the mouse.

- Windows and Linux keep the native minimize, maximize and close buttons. The application menu is reached through a discreet button, with the usual keyboard shortcuts.
- macOS keeps the three traffic-light buttons on the left and the menu in the system menu bar.
- Onboarding and loading screens also reserve the space for this bar. Sillage Server in the browser keeps its usual layout.

## Google Gemini with Antigravity

Sillage supports the official Google Antigravity ACP distribution: Google accounts and Gemini API keys, model and effort choice, permissions, commands, skills, MCP and history import. The integration is available in Server and Desktop.

Handing off to another agent and resuming from a turn use Sillage's portable context when the protocol offers no native fork. Manual compaction and steering during a turn are not available in this protocol. [Coverage and limits](https://github.com/MarlBurroW/sillage/blob/v0.26.0/docs/antigravity-integration.md).

## Readability and stability

- Tool calls favor their human-readable descriptions and keep their final arguments, including after a reconnection.
- Web searches and page opens present their targets and inputs better.
- The crash that could occur while resizing the side panels is fixed.
- The agents' shared instructions stay in English while asking them to respect the user's language.

## Installation and upgrade

Desktop packages are available for Windows x64, macOS Apple Silicon and Linux x64/arm64. Server archives and the multi-architecture Docker image are published as well.

Desktop downloads the update automatically; it can be installed from **Settings › About** or when the app closes, except for the `.deb` package, which needs an explicit installation.

This official release updates **Sillage**. The separate **Sillage Test** edition used to try the window bar keeps its own data and can be uninstalled independently.
