Fixes how Claude Code is launched in "Allow everything" mode, in both Sillage Server and Sillage Desktop.

- Pass the authorization the Claude SDK requires explicitly, in addition to the permission mode, for new conversations and resumes alike.
- Request a restart of the Claude process in both directions when switching to or from "Allow everything".
- Add diagnostic logs when Claude reports another mode or asks for a permission despite this setting, without logging tool arguments.

This fix answers a report of unexpected Bash permission requests on Desktop for Windows. Whether the symptom is gone on the affected installation is yet to be confirmed.

Validation: 355 tests, type checking and lint passed. The new tests go through the real SDK to check the launch and resume arguments.
