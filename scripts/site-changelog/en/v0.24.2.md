Fixes Sillage Desktop crashing when its server reaches 256 MB of JavaScript memory, even on a machine with free RAM.

- Remove the fixed 256 MB cap on the bundled server: Node now sizes its memory limit to the machine.
- The fix concerns Sillage Desktop on Windows, macOS and Linux. Sillage Server's memory settings do not change.
- The repository's documentation and comments are now in English; the README and the guides have also been reorganized.

To update an older Desktop version, close Sillage, then run the new installer. This version does not include automatic updates yet. It also replaces the manual memory-limit fix applied in app.asar.

Validation: type checking, lint and 355 tests passed. A trial of the Desktop launcher with an allocation above 300 MB confirmed that the process starts and stops. A restart with the affected Windows user's data is yet to be confirmed.
